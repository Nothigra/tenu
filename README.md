# Tenu

Prototype d'app mobile de mode : tenue du jour, essayage de styles par IA, dressing, amis et prêts.

- `index.html` : l'app complète (HTML, CSS et JS dans un seul fichier)
- `manifest.webmanifest` + icônes : installation sur l'écran d'accueil

Déployé automatiquement sur Vercel à chaque push sur `main`.
